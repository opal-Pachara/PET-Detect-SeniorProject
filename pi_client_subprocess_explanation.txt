================================================================================
                    อธิบายโค้ด pi_client_subprocess.py
                    PET Detect System - Raspberry Pi Client
================================================================================

📋 ภาพรวมของระบบ
================
pi_client_subprocess.py เป็นไฟล์หลักที่ทำงานบน Raspberry Pi สำหรับระบบตรวจจับ
และแยกประเภทขวด PET โดยใช้ AI และควบคุมฮาร์ดแวร์ต่างๆ

🎯 วัตถุประสงค์หลัก
==================
1. อ่านบัตร RFID ผ่าน subprocess เพื่อหลีกเลี่ยง GPIO conflict
2. ถ่ายภาพวัตถุที่ต้องการแยกประเภท
3. ส่งภาพไปยัง AI API บน Cloud เพื่อวิเคราะห์
4. แสดงผลการตรวจจับบน LCD Display
5. ควบคุม Stepper Motor เพื่อแยกวัตถุ
6. ควบคุม LED เพื่อแสดงสถานะ
7. บันทึกคะแนนลงฐานข้อมูลบน Cloud

📦 การ Import และ Dependencies
=============================
- time, cv2, logging, requests, signal, sys, subprocess, os, json
- RPi.GPIO: สำหรับควบคุม GPIO pins
- stepper_motor_controller: สำหรับควบคุมมอเตอร์
- RPLCD.i2c: สำหรับควบคุม LCD Display (optional)

🔧 คลาสหลัก: PETDetectSubprocess
================================

📌 Constructor (__init__)
-------------------------
- ตั้งค่า API URL สำหรับ AI API บน Cloud
- กำหนด GPIO pin สำหรับ LED (GPIO 4)
- ตั้งค่า signal handler สำหรับการหยุดระบบ
- สร้าง requests session สำหรับ API calls
- สร้าง RFID helper script
- ตั้งค่า LED และ Stepper Motor

📌 ฟังก์ชันควบคุม LED
---------------------
1. setup_led(): ตั้งค่า GPIO pin และทดสอบ LED
2. led_on(duration): เปิด LED เป็นเวลาที่กำหนด
3. led_blink(times, interval): กระพริบ LED
4. led_off(): ปิด LED

📌 ฟังก์ชันควบคุม LCD Display
-----------------------------
1. setup_lcd(): ตั้งค่า LCD และแสดงข้อความเริ่มต้น
2. lcd_show_waiting(): แสดง "กรุณาแตะบัตร"
3. lcd_show_rfid(card_id): แสดงเลข RFID
4. lcd_show_scanning(): แสดง "กำลังสแกน..."
5. lcd_show_results(): แสดงผลการตรวจจับ (ขวด, ฝา, สลาก, กระป๋อง)
6. lcd_show_score(): แสดงคะแนนรวมพร้อมเลขบัตร

📌 ฟังก์ชัน RFID
----------------
1. create_rfid_helper(): สร้าง script สำหรับอ่าน RFID แยก process
2. read_rfid_subprocess(timeout): อ่าน RFID ผ่าน subprocess
   - ใช้ subprocess.run() เพื่อรัน rfid_helper.py
   - หลีกเลี่ยง GPIO conflict ระหว่าง RFID และ hardware อื่น
   - เปิด LED เมื่อตรวจพบบัตร RFID

📌 ฟังก์ชันกล้อง
----------------
1. open_camera(): เปิดกล้องและตั้งค่าความละเอียด (640x480)
2. capture_image(): ถ่ายภาพและบันทึกเป็นไฟล์
3. close_camera(): ปิดกล้อง

📌 ฟังก์ชัน API
---------------
1. send_image_to_api(image_path): ส่งภาพไปยัง AI API บน Cloud
   - URL: https://pet-detect-ai-api.onrender.com/api/scan
   - ใช้ POST request พร้อมไฟล์ภาพ
   - รับผลการวิเคราะห์กลับมา

📌 ฟังก์ชันประมวลผลผลลัพธ์
--------------------------
1. process_scan_result(result_data, card_id):
   - แสดงผลการตรวจจับบน console และ LCD
   - แสดงจำนวนขวด, กระป๋อง, ฝา, สลาก
   - แสดงคะแนนรวม
   - บันทึกคะแนนลงฐานข้อมูล

2. save_score_to_web(card_id, result):
   - ส่งข้อมูลคะแนนไปยัง Web Score System
   - URL: https://pet-detect-seniorproject-1.onrender.com/api/add_score
   - มี retry logic (3 ครั้ง) สำหรับความเสถียร
   - ข้อมูลที่ส่ง: card_id, bottle_count, can_count, cap_count, label_count, score

📌 ฟังก์ชันควบคุม Stepper Motor
-------------------------------
control_stepper(result_data):
- ตรวจสอบผลการตรวจจับ
- ควบคุมการหมุนมอเตอร์ตามวัตถุที่พบ:
  * พบขวด: หมุนซ้าย 90°
  * พบกระป๋อง: หมุนขวา 90°
  * พบทั้งคู่: หมุนขวา 90°
- หมุนกลับตำแหน่งเริ่มต้น
- ใช้ความเร็ว 150 steps/sec เพื่อความนุ่มนวล

📌 ฟังก์ชันหลัก
---------------
1. run_single_scan(): รันการสแกนครั้งเดียว
   - อ่าน RFID
   - ถ่ายภาพ
   - ส่งไป AI API
   - แสดงผลและบันทึกคะแนน
   - ควบคุมมอเตอร์
   - ปิด LED

2. run_continuous_scan_system(): รันระบบต่อเนื่อง
   - ตั้งค่า LCD
   - รันลูปการสแกนไม่สิ้นสุด
   - จัดการ error และ timeout

3. cleanup(): ทำความสะอาดเมื่อจบการทำงาน
   - ปิดกล้อง
   - ปิด LCD
   - ปิด LED
   - ลบไฟล์ helper script

🔄 Flow การทำงาน
================
1. เริ่มต้นระบบ → ตั้งค่า hardware → แสดง "กรุณาแตะบัตร"
2. รอการแตะบัตร RFID → เปิด LED → แสดงเลข RFID
3. แสดง "กำลังสแกน..." → เปิดกล้อง → ถ่ายภาพ
4. ส่งภาพไป AI API → รับผลการวิเคราะห์
5. แสดงผลบน LCD → บันทึกคะแนนลงฐานข้อมูล
6. ควบคุม Stepper Motor → หมุนกลับตำแหน่งเดิม
7. ปิด LED → รอรอบต่อไป

🌐 การเชื่อมต่อ Cloud
====================
- AI API: https://pet-detect-ai-api.onrender.com
- Web Score System: https://pet-detect-seniorproject-1.onrender.com
- ใช้ HTTPS สำหรับความปลอดภัย
- มี timeout และ retry logic

🔧 การตั้งค่า Hardware
=====================
- LED: GPIO 4 (ต่อกับ Relay)
- Stepper Motor: GPIO 18 (step), GPIO 19 (direction)
- LCD: I2C Address 0x27 (PCF8574)
- RFID: SPI interface (MFRC522)
- Camera: USB Camera (/dev/video0)

⚡ การจัดการ Error
==================
- มี try-catch ในทุกฟังก์ชันสำคัญ
- มี timeout สำหรับ RFID และ API calls
- มี retry logic สำหรับการบันทึกคะแนน
- มี signal handler สำหรับการหยุดระบบอย่างปลอดภัย

📊 ข้อมูลที่บันทึก
==================
- RFID Card ID
- จำนวนขวด (bottle_count)
- จำนวนกระป๋อง (can_count)
- จำนวนฝา (cap_count)
- จำนวนสลาก (label_count)
- คะแนนรวม (score)
- ภาพที่ถ่าย (image_path)

🎯 จุดเด่นของระบบ
=================
1. ใช้ subprocess สำหรับ RFID เพื่อหลีกเลี่ยง GPIO conflict
2. เชื่อมต่อ Cloud API สำหรับ AI processing
3. มี LCD Display แสดงสถานะแบบ real-time
4. ควบคุม Stepper Motor แบบอัตโนมัติ
5. มี retry logic และ error handling ที่ดี
6. บันทึกข้อมูลลงฐานข้อมูลบน Cloud
7. รองรับการทำงานแบบต่อเนื่อง

🔧 การใช้งาน
============
1. รันคำสั่ง: python3 pi_client_subprocess.py
2. วางบัตร RFID ใกล้ตัวอ่าน
3. ระบบจะทำงานอัตโนมัติ
4. กด Ctrl+C เพื่อหยุดระบบ

📝 หมายเหตุ
===========
- ไฟล์นี้เป็นเวอร์ชันที่ปรับปรุงแล้วสำหรับการใช้งานจริง
- ใช้ Cloud API แทน local API เพื่อความเสถียร
- มีการจัดการ GPIO conflict อย่างเหมาะสม
- รองรับการทำงานแบบ standalone บน Raspberry Pi
