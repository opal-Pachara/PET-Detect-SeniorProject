ส่วนหนึ่งของการศึกษาในโครงการ PET Detect Senior Project โดยมุ่งเน้นการทดสอบการยอมรับ

(YOLOv11) ระบบออกแบบมาเพื่อให้ผู้ใช้งานสามารถสแกนขวด PET ผ่านเครื่องอ่าน RFID รับผล

ผู้ทดสอบจะดำเนินการตามขั้นตอนในเอกสารและบันทึกผลการทดสอบ โดยภาพประกอบจะเว้นไว้
ให้ผู้ทดสอบถ่ายและนำมาใส่ภายหลัง

ผู้ใช้ฝ่ายสมาชิก/ทั่วไป

1. การดูหน้าหลักและตารางคะแนนสมาชิก

การเข้าถึงระบบผ่านหน้าเว็บ PET Detect มีขั้นตอนดังนี้

1. เปิดเว็บเบราว์เซอร์และเข้าสู่ URL ของระบบ PET Detect (หน้า /)
2. ที่หน้าแรกของระบบ ตรวจสอบว่ามีการ์ดสถิติแสดง
   2.1 สมาชิกทั้งหมด (Total Members)
   2.2 คะแนนรวม (Total Score)
   2.3 จำนวนการสแกน (Total Scans)
3. ตรวจสอบตารางสมาชิกเรียงตามคะแนนสูงไปต่ำ (หรือข้อความว่าไม่มีข้อมูลถ้ายังไม่มีการสแกน)
4. ตรวจสอบปุ่ม Admin Login หรือเมนูที่เกี่ยวข้อง

1. การแตะบัตร RFID และเริ่มกระบวนการสแกน

ภาพที่ 2-1: หน้า /admin/login ก่อนกรอกข้อมูล
ภาพที่ 2-2: ข้อความแจ้งเตือนเมื่อกรอก username/password ผิด
ภาพที่ 3-1: หน้าแดชบอร์ด Admin หลัง login สำเร็จ
ภาพที่ 3-2: หน้า manage_members แสดงตารางสมาชิก
ภาพที่ 3-3: หน้า/modal แก้ไขคะแนนสมาชิก
ภาพที่ 4-1: หน้า scan_history แสดงรายการสแกน
ภาพที่ 4-2: หน้า stats แสดงสถิติ
ภาพที่ 5-1: ภาพอุปกรณ์ Raspberry Pi ทั้งชุด (RFID, กล้อง, LCD)
ภาพที่ 5-2: LCD แสดง "กรุณาแตะบัตร" หรือ "Waiting..."
ภาพที่ 5-3: LCD แสดงผลหลังสแกน (คะแนน/จำนวนขวด)
ภาพที่ 5-4: LED ติดเมื่อแตะบัตร RFID (optional)
ภาพที่ 6-1: Response JSON จาก POST /api/scan
