สรุปฟีเจอร์เซ็นเซอร์เสียง (Buzzer):
===================================

1. **Hardware Setup**: 
   - GPIO Pin 17 สำหรับ Buzzer
   - โมดูล Buzzer 3 ขา (VCC/GND/I/O)
   - Active-LOW Logic: LOW = ดัง, HIGH = เงียบ

2. **ฟังก์ชันหลัก**:
   - setup_buzzer(): ตั้งค่า GPIO และให้เงียบตอนเริ่มต้น
   - buzzer_beep(): ส่งเสียงสัญญาณสั้น ๆ 0.15 วินาที
   - _silence_buzzer_on_exit(): ปิดเสียงเมื่อโปรแกรมจบ

3. **การใช้งาน**:
   - เสียงแจ้งเตือนเมื่อแตะบัตร RFID สำเร็จ (บรรทัดที่ 325)
   - ป้องกันเสียงดังค้างเมื่อโปรแกรมหยุดทำงาน

4. **ข้อดี**:
   - มีระบบ cleanup ป้องกันเสียงค้าง
   - เสียงสัญญาณให้ User feedback ทันที
   - ควบคุมง่ายด้วย Active-LOW Logic
