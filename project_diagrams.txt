📋 USE CASE DESCRIPTIONS
================================================================================

🎯 ผู้ใช้ (User):
- ดูตารางคะแนน (Leaderboard): ดูอันดับคะแนนของสมาชิกทั้งหมด

🔧 ผู้ดูแลระบบ (Admin):
- เข้าสู่ระบบ: ล็อกอินด้วย username/password
- ดูสถิติระบบ: ดูสถิติการใช้งานระบบ (สมาชิก, การสแกน, คะแนน)
- จัดการสมาชิก: ดูรายชื่อสมาชิกที่สแกน RFID แล้ว
- ดูประวัติการสแกน: ดูประวัติการสแกนทั้งหมด
- แก้ไขคะแนน: แก้ไขคะแนนของสมาชิก
- ลบสมาชิก: ลบข้อมูลการสแกนของสมาชิก

🤖 Raspberry Pi Client:
- สแกน RFID: อ่านบัตร RFID ผ่าน MFRC522
- ถ่ายภาพ: ถ่ายภาพวัตถุด้วยกล้อง USB
- ส่งภาพไป AI API: ส่งภาพไปวิเคราะห์บน Cloud
- ควบคุม Stepper Motor: หมุนมอเตอร์ตามผลการวิเคราะห์
- บันทึกคะแนน: ส่งข้อมูลคะแนนไป Web Score System
- แสดงผลบน LCD: แสดงผลการตรวจจับบน LCD 16x2

📊 TABLE DESCRIPTIONS
================================================================================

🗃️ MEMBERS Table:
- id: Primary Key (Auto Increment)
- rfid_id: RFID Card ID (Unique, String)
- username: Username (String)
- password_hash: Hashed Password (String)
- full_name: Full Name (String)
- email: Email Address (String)
- phone: Phone Number (String)
- total_score: Total Score (Integer, Default: 0)
- created_at: Creation Timestamp
- updated_at: Last Update Timestamp

🗃️ SCAN_LOGS Table:
- id: Primary Key (Auto Increment)
- rfid_id: Foreign Key → MEMBERS.rfid_id (String)
- bottle_count: Number of Bottles Detected (Integer)
- can_count: Number of Cans Detected (Integer)
- cap_count: Number of Caps Detected (Integer)
- label_count: Number of Labels Detected (Integer)
- score: Calculated Score (Integer)
- image_path: Path to Captured Image (String)
- scan_time: Scan Timestamp

================================================================================
📈 SCORING SYSTEM
================================================================================

🎯 New Scoring System:
- ขวด PET (Bottles): +50 คะแนน
- กระป๋อง (Cans): +100 คะแนน
- ฝา (Caps): -10 คะแนน
- สลาก (Labels): -10 คะแนน

📊 Score Calculation Formula:
Score = (bottle_count × 50) + (can_count × 100) - (cap_count × 10) - (label_count × 10)

📝 Example:
- ขวด 2 อัน = +100 คะแนน
- กระป๋อง 1 อัน = +100 คะแนน
- ฝา 1 อัน = -10 คะแนน
- สลาก 0 อัน = 0 คะแนน
- รวม = 190 คะแนน

================================================================================
🔌 HARDWARE CONNECTIONS
================================================================================

🔌 Raspberry Pi GPIO Connections:
- GPIO 4 → LED (ผ่าน Relay)
- GPIO 18 → Stepper Motor (Step)
- GPIO 19 → Stepper Motor (Direction)
- I2C → LCD Display (Address 0x27)
- SPI → RFID Reader (MFRC522)
- USB → Camera

⚡ Power Requirements:
- Raspberry Pi: 5V/3A (USB-C)
- Stepper Motor: 12V/24V (External Power Supply)
- LCD Display: 5V (I2C)
- RFID Reader: 3.3V (SPI)
- LED: 5V (ผ่าน Relay)

-- PostgreSQL/SQLite Schema
CREATE TABLE members (
    id SERIAL PRIMARY KEY,                    -- PostgreSQL
    -- id INTEGER PRIMARY KEY AUTOINCREMENT,  -- SQLite
    rfid_id VARCHAR(50) UNIQUE NOT NULL,      -- PostgreSQL
    -- rfid_id TEXT UNIQUE NOT NULL,          -- SQLite
    username VARCHAR(100),                    -- PostgreSQL
    -- username TEXT,                         -- SQLite
    password_hash VARCHAR(255),               -- PostgreSQL
    -- password_hash TEXT,                    -- SQLite
    full_name VARCHAR(200),                   -- PostgreSQL
    -- full_name TEXT,                        -- SQLite
    email VARCHAR(100),                       -- PostgreSQL
    -- email TEXT,                            -- SQLite
    phone VARCHAR(20),                        -- PostgreSQL
    -- phone TEXT,                            -- SQLite
    total_score INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE scan_logs (
    id SERIAL PRIMARY KEY,                    -- PostgreSQL
    -- id INTEGER PRIMARY KEY AUTOINCREMENT,  -- SQLite
    rfid_id VARCHAR(50) NOT NULL,             -- PostgreSQL
    -- rfid_id TEXT NOT NULL,                 -- SQLite
    bottle_count INTEGER DEFAULT 0,
    can_count INTEGER DEFAULT 0,
    cap_count INTEGER DEFAULT 0,
    label_count INTEGER DEFAULT 0,
    score INTEGER DEFAULT 0,
    image_path VARCHAR(500),                  -- PostgreSQL
    -- image_path TEXT,                       -- SQLite
    scan_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Foreign Key Relationship
ALTER TABLE scan_logs ADD CONSTRAINT fk_scan_logs_rfid_id 
FOREIGN KEY (rfid_id) REFERENCES members(rfid_id);
