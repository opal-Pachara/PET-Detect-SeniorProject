                         DATA FLOW DIAGRAM

┌─────────────┐
│    USER     │
│  (Tap RFID) │
└──────┬──────┘
       │
       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  STEP 1: RFID DETECTION                                                     │
│  ────────────────────────────────────────────────────────────────────────   │
│  • RFID Reader detects card                                                 │
│  • Read RFID ID                                                             │
│  • Send to main process via pipe                                            │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  STEP 2: IMAGE CAPTURE                                                      │
│  ────────────────────────────────────────────────────────────────────────   │
│  • Main process receives RFID ID                                            │
│  • Display "Processing..." on LCD                                           │
│  • Capture image from USB camera                                            │
│  • Save image temporarily                                                   │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  STEP 3: AI DETECTION                                                       │
│  ────────────────────────────────────────────────────────────────────────   │
│  • Send image to AI API (POST /api/detect)                                  │
│  • YOLO v5 processes image                                                  │
│  • Detect and count objects:                                                │
│      - PET Bottles                                                          │
│      - Cans                                                                 │
│      - Caps                                                                 │
│      - Labels                                                               │
│  • Return counts to Raspberry Pi                                            │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  STEP 4: SCORE CALCULATION (ON RASPBERRY PI)                                │
│  ────────────────────────────────────────────────────────────────────────   │
│  • Calculate score:                                                         │
│      score = (bottles × 50) + (cans × 100) - (caps × 10) - (labels × 10)   │
│  • Display results on LCD:                                                  │
│      Line 1: "B:<n> C:<n> Cap:<n> L:<n>"                                    │
│      Line 2: "Total: <score> pts"                                           │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  STEP 5: SAVE TO WEB SYSTEM                                                 │
│  ────────────────────────────────────────────────────────────────────────   │
│  • Send data to web API (POST /api/add_score)                               │
│  • Request body:                                                            │
│      {                                                                      │
│        "rfid_id": "XXXXXXXXXX",                                             │
│        "bottle_count": int,                                                 │
│        "can_count": int,                                                    │
│        "cap_count": int,                                                    │
│        "label_count": int,                                                  │
│        "score": int                                                         │
│      }                                                                      │
│  • Flask app receives data                                                  │
│  • Insert into scan_logs table                                              │
│  • Return success/error response                                            │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  STEP 6: MOTOR CONTROL                                                      │
│  ────────────────────────────────────────────────────────────────────────   │
│  • If score > 0: Open door (stepper motor rotate)                           │
│  • Wait 3 seconds                                                           │
│  • Close door                                                               │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
                                       ▼
                              ┌─────────────┐
                              │   COMPLETE  │
                              │ (Back to    │
                              │  Idle Mode) │
                              └─────────────┘
